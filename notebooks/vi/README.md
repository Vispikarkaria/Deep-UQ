# Variational Inference Notebooks

This folder contains the VI tutorial family for Deep-UQ.

- `BayesByBackprop_Tutorial.ipynb` — baseline mean-field Bayes by Backprop
- `Heteroscedastic_BayesByBackprop_ADR1D_Tutorial.ipynb` — regression with input-dependent noise
- `MultiOutput_BayesByBackprop_ElasticBar1D_Tutorial.ipynb` — multi-output regression
- `HeteroscedasticMultiOutput_BayesByBackprop_Transport2D_Tutorial.ipynb` — multi-output regression with aleatoric noise
- `LastLayerVI_Heat2D_Classification_Tutorial.ipynb` — scalable last-layer VI for classification
