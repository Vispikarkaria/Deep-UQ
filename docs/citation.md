# Citing Deep-UQ

If Deep-UQ is useful in your research, please consider citing it.

## BibTeX

```bibtex
@software{deepuq2024,
  author       = {Karkaria, Vispi Nevile and Contributors},
  title        = {Deep-UQ: Unified Deep Learning Uncertainty Quantification Toolkit},
  year         = {2024},
  publisher    = {GitHub},
  url          = {https://github.com/Vispikarkaria/Deep-UQ},
  license      = {MIT}
}
```

## CITATION.cff

A machine-readable [`CITATION.cff`](https://github.com/Vispikarkaria/Deep-UQ/blob/master/CITATION.cff) file is included in the repository root for automatic citation generation on GitHub.

## Badge

You can add a Deep-UQ badge to your project:

```markdown
[![Deep-UQ](https://img.shields.io/badge/UQ-Deep--UQ-0b84f3)](https://github.com/Vispikarkaria/Deep-UQ)
```
